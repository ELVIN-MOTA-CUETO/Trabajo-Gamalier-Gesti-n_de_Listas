# Descripción del proyecto

El proyecto que trata de un programa que contiene un menú de opciones de una tienda, en el cual se
puede agregar, mostrar, buscar y elminar productos de la lista, como asi mismo se puede mostrar
la estadistica (precio mayor, menor, promedio y total) y ordenar de manera acendente o descendente.

# Entrada:

-opcion del menu

-los datos que requiere para seguir ejecutando los metodos en cada uno de los casos, por ejemplo: 

al momento de modificar un producto el programa te pregunta, cual producto se mofificará?, que nombre tendrá? y ¿que precio?

# Proceso

El programa hace lo siguiente:

-recibe la opcion que elige el usuario del menú

-dependiendo la opción que se elija se ejecuta el metodo corrrespondiente

# Salida

muestra:

-lo que pida el usuario del menu: ejemplo: productos en la lista: 

----------
nombre-producto: $papas
precio: $90000
